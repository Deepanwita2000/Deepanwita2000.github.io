# Deepanwita Sarkar — Developer Portfolio

A responsive static portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract this ZIP file.
2. Open `index.html` in a browser.

## Before publishing — important
Update the placeholder project links in `index.html`:
- Search for `data-placeholder`.
- Replace each `href="#"` with the actual GitHub repository or live-demo URL.
- Add your LinkedIn and GitHub profile links if you want them displayed (the resume provided did not contain the actual URLs).

The resume PDF is included at `assets/Deepanwita_Sarkar_Resume.pdf`.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload the contents of this folder (not the containing folder itself).
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Your site will be available at `https://YOUR_GITHUB_USERNAME.github.io/`.

GitHub Pages supports static HTML/CSS/JavaScript. This portfolio does not require a Django server.
